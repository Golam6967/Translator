**These numbers measure Gemini's free-tier quota, not the fallback mechanism.** A 429 response from this key reported `GenerateRequestsPerDayPerProjectPerModel-FreeTier` with a limit of 20 requests per model per day, and a sentence uses 3 calls. Earlier runs were mostly limited by 503 overload and by that daily quota; the run after the quota was used up got no answers at all. The fallback path itself is covered by unit tests and by manual forced-failure calls that were answered by Gemini. A meaningful reliability figure needs a key with real quota.
